# Patwary Net ISP website

Static, responsive website built with HTML, CSS and vanilla JavaScript.

## Preview

Open `index.html` in a modern browser. No build step or package installation is required. Google Fonts are loaded from Google Fonts when online; system font fallbacks are included.

## Included

- Responsive corporate site with navy and cyan styling
- Seven supplied speed and price options, plus the supplied 1:8 contention ratio
- English/Bangla text toggle
- Click-to-call phone links and click-to-email contact
- Coverage inquiry form that drafts an email to `patwarynet2018@gmail.com`
- FAQ and mobile navigation

## Static-site limits

The coverage form does not verify service availability. It opens the visitor’s email application with an inquiry draft. A live coverage checker, customer signup, payment collection, account management, service-status notifications, installation scheduling, and stored form submissions need a backend or connected business systems. Package prices are shown as supplied; billing period and current availability were not confirmed.

The referenced `patwarynet.bd` site could not be accessed during implementation, and no indexed business details were found. This page therefore uses only the name, package details, ratio, phone numbers, and email supplied in the request. Confirm coverage areas, company/legal name, billing period, installation terms, operating hours, and any service claims before publishing.
